# Smart Life — Premium Personal Life Toolkit

Smart Life is an AI-ready, offline-first personal productivity and everyday life management Progressive Web App (PWA) built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- **Main Dashboard**: Personalized welcome banner, live productivity score ring, today's overview, daily tasks & habits, interactive calendar, goals, routine timeline, quick tools, favorites, recent activities, and 7 functional SVG charts.
- **Daily Planner**: Daily, weekly, and monthly planners, task manager with priorities, quick checklists, morning/afternoon/evening routine planner, and hourly time blocking.
- **Habit Tracker**: Habit creation, daily check-ins, consecutive streak tracking, weekly & monthly progress, habit calendar grid, and completion stats.
- **Goal Management**: Personal, financial, health & fitness, career, and learning goals with deadlines, progress tracking, and milestone checklists.
- **Personal Finance**: Expense & income tracker, editable monthly budget with automatic alert banners, savings goal tracker, category breakdown chart, and transaction history.
- **Time Management**: Pomodoro timer (customizable work/break), focus timer, countdown timer, stopwatch with laps, break reminders UI, and logged work sessions.
- **Health & Lifestyle**: Personal lifestyle tracking (non-medical) including water intake, sleep log, manual walking tracker, exercise planner, weekly meal planner, wellness journal, and daily wellness checklist.
- **Personal Organizer**: Notes, personal diary/journal, important dates & birthday countdowns, event planner, shopping & grocery lists, travel checklist, and document checklist.
- **AI Everyday Assistant**: 10 structured prompt templates, clearly labelled Demo Mode local template engine (never pretends a real external API call was made), optional user-configured provider/endpoint settings (keys stay only in your browser), loading states, error handling, and saved history.
- **Smart Life Premium**: Transparent ₹399/month subscription interface with status view, billing preview placeholder (no fake payment processing), and cancellation flow.
- **PWA & Portability**: Offline service worker, installable manifest, light/dark themes, JSON export/import, and 100% LocalStorage persistence.

## Deployment (GitHub Pages Compatible)
All paths are relative (`./`). Upload the `smart-life/` directory contents to any static host or GitHub Pages repository root and enable GitHub Pages.
